# Duual — Compatibilidad Astrológica Real

🔮 **[duual-web.vercel.app](https://duual-web.vercel.app)** — Calcula tu carta astral de pareja gratis con sinastría real, no horóscopos genéricos.

Duual es una calculadora de compatibilidad astrológica bilingüe (ES/EN) basada en carta natal completa, usando un motor astronómico real en vez de textos genéricos de signo solar. Incluye análisis de sinastría, aspectos planetarios y compatibilidad por áreas de pareja.

- 🌐 Web (gratis): [duual-web.vercel.app](https://duual-web.vercel.app)
- 📱 App Android: [Play Store](https://play.google.com/store/apps/details?id=com.duual.app)

## Stack

HTML/CSS/JS puro, sin frameworks. [Astronomy Engine](https://github.com/cosinekitty/astronomy) para cálculos planetarios. Desplegado en Vercel.
